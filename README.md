This is a console application simulating a simple ERP system. It allows you to create a company, define its products using a structure called a Blueprint, 
manage customers, and process their orders—including purchasing raw materials, crafting final products, and completing sales. Every item (whether a raw material 
or a finished product) is represented by a Blueprint, which can be recursively composed of other blueprints.
The application currently simulates the ERP system of a KFC restaurant chain and is fully implemented using Object-Oriented Programming (OOP) in C#
